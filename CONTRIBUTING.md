# Contributing to PixelCodex

Thank you for your interest in contributing to PixelCodex! This document provides guidelines and information for contributors.

## 🤝 How to Contribute

### Reporting Issues
- Use GitHub Issues to report bugs or suggest features
- Include detailed information about the problem
- Provide steps to reproduce issues
- Include screenshots when relevant

### Development Setup
1. Follow the setup instructions in the README.md
2. Create a branch for your feature/fix
3. Make your changes following the code style
4. Test your changes thoroughly
5. Submit a pull request

### Code Style Guidelines
- Follow Android development best practices
- Use meaningful variable and method names
- Add comments for complex logic
- Maintain consistent formatting
- Update documentation when needed

### Pull Request Process
1. Fork the repository
2. Create a descriptive branch name
3. Make focused, atomic commits
4. Write clear commit messages
5. Test your changes
6. Update relevant documentation
7. Submit the pull request

## 📋 Development Guidelines

### Code Quality
- Write clean, readable code
- Follow SOLID principles
- Add unit tests for new features
- Ensure no breaking changes

### UI/UX Considerations
- Follow Material Design guidelines
- Maintain accessibility standards
- Test on multiple screen sizes
- Consider performance impact
